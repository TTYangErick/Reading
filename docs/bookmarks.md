# 书签契约

项目状态、证据与下一步只维护在 `../PLAN.md`。

- 阅读操作面板提供“书签”；滚动手机沿原顶部控件提供同名入口。面板内添加当前位置、查看本书书签与确认删除，不改变正文布局。按创建时间倒序，摘要来自真实源文字；图片无图注、空表格使用明确占位标题。
- 分页记录当前可见物理页起点，双页记录左页起点。滚动记录当前首个可见块起点（段落级，不声称逐行精确）；图片记录image，表格记录首行。分页图注与表格续行分别保存caption/UTF-16偏移、tableRow/行号。正文和补充文档始终使用独立命名空间。
- drift schema6只新增bookmarks：UUID、book_id、规范PageAnchor v1 location、excerpt、created_at/updated_at毫秒时间戳；唯一键book_id/location，同位置重复保存保持原ID与日期。所有旧业务表/内容JSON/阅读位置格式不变。删除书签限定书籍与自身ID，删除书籍同事务删除其书签；生词快照仍保留。改书名不改位置，重新导入的新书不会自动绑定旧书签。
- 新增时从当前数据库读取原书并验证锚点；跳转时拒绝坏JSON/未知版本、越界文档/块/偏移、错误媒体类型/行号，不静默夹取到别处。书籍内容在现有产品中不可编辑；摘要为添加时快照，不承诺未来编辑书籍后的自动重定位。
- 点击书签复用reading-link临时阅读路由，额外传递完整PageAnchor，caption与表格行在单/双页及滚动均显露。保留原阅读设置、目录、查词/翻译、逐层返回与返回原阅读处；来自生词原句时沿其原路由返回。不写正文进度，主动设置修改仍按原规则持久化。用户需要继续主阅读时从原正文阅读入口沿原进度恢复。
- 书签跳转不误用EPUB backlink匹配，但后续真实链接仍使用原返回规则；连续打开沿现有16层限制，重复打开保护沿用openLink。打开失败可返回，失效书签可删除。列表加载/添加/删除有失败重试，保存中禁用重复操作；已有位置显示“此位置已添加书签”。
- 不加入同步、书签编辑/标签或全文搜索。首版按书全量读取后列表按需构建，大规模书签性能未验证。当前只支持所用分页器已有的文字、图片与简单表格能力。
