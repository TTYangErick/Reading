# 生词本契约

项目状态与下一步只维护在 `../PLAN.md`。

## 收藏与来源

- 收藏入口只出现在完整释义卡片。极简/简洁气泡不增加按钮；点词、展开、关闭与默认英汉布局沿用原行为。未收录或仍在加载的词不生成假释义记录。
- 保存当前显示语言的释义：默认兼容完整卡片保存 ECDICT 中文；主动选择英英或跨语言展开到英英时保存 Wiktionary 英文。保存选中的原词、对应原形、释义快照、来源与许可。英英快照最多取当前卡片展示的 24 条，含词性/限定标签，不自动推断上下文词义。
- `VocabularyDraft.capture` 从原始块获取原句，独立脚注使用补充文档命名空间，表格使用具体行列单元格，图注使用原图注文字。`location` JSON version 1 包含 BookPosition（块、UTF-16 偏移、可选 document）和可选 cell（`行-列` 或 `caption`），不存临时页码。
- 同一语言、词典、书籍与来源位置仅一条，重复/并发收藏幂等，保持原 UUID、日期与快照。不同位置或词典可独立收藏。收藏期间切词/关闭不会把旧请求结果写进新卡片状态。

## 存储

- drift schema 5 仅新增 `vocabulary` 表，保持已有 books/book_assets/settings/translations 及内容 JSON 不变。旧版本逐级迁移。
- 每条记录含 UUID、created_at/updated_at 毫秒时间戳、lang、dict_id、word、lemma、gloss、source/source_url/license、book_id/book_title、sentence、location。唯一键为 `(lang,dict_id,book_id,location)`。
- 来源书名和释义是收藏时的快照；删除/改名书籍不会删除或改写生词。删除生词只按自身 id 删除，经用户确认，不影响书籍、资源、进度、设置、词库或译文缓存。
- 当前离线保存，不联网，不做同步/自动导出，不把词典内容当作系统句子翻译。

## 列表

- 书架更多 → 生词本。默认最近收藏在前，可切最早在前；按书籍 id 筛选（书名为快照），对单词、原形、释义、原句和书名作不区分大小写的字面子串搜索，`%`/`_` 不作 SQL 通配符。
- 列表显示释义摘要、原句、书名、日期和词典许可；点击条目查看可选中复制的完整快照及来源 URL。长文本可滚动；空列表、无匹配结果、读取失败重试及删除失败均有反馈。
- 首版读取生词记录后本地筛选、列表按需构建；大规模生词库性能尚未验证。CSV 导出见下方；复习/同步属于后续步骤。

## 回到原句

- 点击列表原句、“在书中查看原句”按钮或详情中的同名入口，按 book_id 读取当前书籍。书不存在时保留收藏并提示；坏 JSON、未知版本、失效文档/块/偏移/单元格、原词或原句不匹配均拒绝跳转，不夹取到别处，也不按书名绑定重新导入的书。
- `VocabularySource.resolve` 将 v1 收藏位置映射为源 BookPosition 与 PageAnchor：普通文字保持 UTF-16 偏移，图注使用 caption，表格使用 tableRow/行号（锚点偏移为0），真实单元格偏移另行用于显露文字。宽表自动滚至对应列，超高单元格显露原词所在行；滚动模式同样定位原文/图注/单元格。
- `ReaderPage.source` 是临时阅读根路由，使用当前全局/单书样式并保留目录、设置、查词及嵌套链接。翻页/滚动/目录浏览、进入后台或关闭都不写正文进度。用户主动改设置仍按原规则保存；亮屏生命周期由本临时根路由管理。
- 返回入口为“返回生词本”；嵌套链接可“返回上一处”或“回到原句”。系统返回逐层退出；回到生词本后保留原搜索、书籍筛选和列表状态。连续快速点击只打开一次，不额外压入普通正文阅读页。
- 点击目录是临时浏览该正文章节，仍不改变书架中原有阅读位置。正常从书架打开书继续沿原进度恢复。


## CSV 导出

- 生词本右上角“导出 CSV”打开范围选择。当前列表包含搜索与书籍筛选；有筛选时也可选择全部生词。两者均沿用当前最新/最早排序，打开范围窗口时冻结记录快照。加载中、读取失败或无收藏时入口禁用；当前筛选无匹配时只能导出全部。保存期间禁止重复导出。
- `VocabExporter` 为纯编码接口，`CsvVocabExporter` 实现固定15列：word、lemma、gloss、sentence、book_title、created_at、lang、dict_id、source、source_url、license、id、book_id、location、updated_at。完整收藏快照包含词典署名、来源URL、许可与稳定来源JSON；不要求原书仍存在，不重新查词或翻译。日期使用UTC ISO8601。
- UTF-8带BOM、逗号分列、CRLF分记录；所有字段双引号包裹，内部双引号重复，保留多行释义/原句。为降低表格公式注入风险，去除前导空白后以`= + - @`及其全角形式开头，或首字符为ASCII控制字符的字段，在导出值前加单引号；收藏原值不改。CSV是文本交换格式，不是可回导的完整备份；其他软件可能显示该单引号。导入Anki等工具时需选择UTF-8/逗号并跳过表头、映射所需列，未实现专用Anki包。
- 复用已锁定file_picker 13.1.0的`saveFile`，传入CSV字节、text/csv和带时间戳文件名，由系统选择保存目标。iOS使用文档导出窗口；Android使用文档创建器。返回非空URI才提示已导出，null代表用户取消而不提示成功；异常提示重试。页面关闭后不更新已销毁界面。
- 不增加依赖、权限、数据库迁移或自动上传；系统保存目标由用户选择。导出只读列表，不修改任何业务表、收藏、源书位置、设置或缓存。系统/插件负责保存及临时文件生命周期；不清理共用文件组件缓存，避免影响已有导入流程。大规模导出内存峰值尚未验证。
