# EPUB 脚注解析第 1 步：正文链接与锚点

2026-10-02。仅数据模型和解析；阅读器尚未处理点击链接或返回。

## 已实现

- `BookPosition(block, offset)`：正文块索引及该块规范化文字的 UTF-16 偏移，可直接对应 Dart 字符串和 Flutter 文本位置。
- `BookLink`：来源块、半开区间 `[start,end)`、原始 `href`、语义 `kind`、目标状态、规范化 `targetKey` 和已解析的目标位置。
- `BookContent.links` / `anchors` 持久化进既有正文 JSON；旧数据缺字段时默认为空，不改数据库 schema，不重解析旧书。
- 普通正文中的 `<a href>`，章内/跨连续阅读章节目标；`epub:type=noteref/backlink` 和 `role=doc-noteref/doc-backlink` 的语义识别。没有语义标记的 EPUB 2 链接仍保留为普通链接，不靠文字猜测脚注。
- 锚点键是包内规范化路径和可选 `#解码ID`；文档开头也有锚点。同一文档重复 ID 采用首次出现者，不同文档的相同 ID 不冲突。文末空锚点不会错误落到下一章。
- `_NormalizedText` 映射空白折叠前后的偏移。行内标签和表情不破坏链接范围；跨多个文本块的链接拆为各块内的有效范围，纯空白链接不生成可点击范围。
- 全部连续正文解析完毕后才解析目标，支持向后或向前引用。链接片段不存在时**不回退到章节起点**；目录旧有回退行为不变。

| status | 意义与后续 UI 约束 |
|---|---|
| resolved | target 非空，允许后续 UI 在书内跳转 |
| missingTarget | 文件/锚点不存在或目标不可定位；不可假装跳转成功 |
| unavailableDocument | 文件存在但没有进入当前连续阅读内容，包括 linear=no、非 spine 页和其他资源；不能当成已支持脚注 |
| external | URI 有 scheme/authority；仅保存，不联网、不执行。包括 javascript 等 URI，UI 不得据此直接打开 |
| invalid | 错误转义、越界路径或暂不支持的查询参数；保留文字，不阻断导入 |

## 明确未完成

- **独立脚注页**：`linear=no` 或不在 spine 的 HTML 不载入、不附加到正文，链接明确标为 unavailableDocument。这是下一独立步骤，不能声称完整脚注支持。
- **交互**：没有链接样式、点击跳转、返回栈或脚注弹层；现有点词不变。两端未安装本轮构建，原生视觉未验收。
- **范围**：只保留普通正文文字链接。表格单元格内的链接、图片链接、旧式 `<a name>` 锚点尚不支持；链接文字本身仍沿用原有正文/表格提取。
- 不支持通用 SVG、原书 CSS 精确排版和隐藏样式语义；现有媒体/复杂表格边界不变。
