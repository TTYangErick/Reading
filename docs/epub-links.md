# EPUB 链接与独立脚注页：解析、存储与阅读契约

本文件维护当前阅读、分页与链接契约。工程证据、已确认体验和未关闭事项统一见 [PLAN.md](../PLAN.md)；旧阶段记录不作为当前能力限制。

## 内容与位置命名空间

- `BookContent.blocks` 仍只包含连续正文，按原 spine 顺序生成；补充页不会插入/追加到正文，不参与 `contents`、目录目标、`Book.position` 或 `Book.progress`。
- `BookContent.supplementaryDocuments` 是包内规范化路径到 `List<BookBlock>` 的映射，保存被引用的 `linear=no` 或非 spine HTML/XHTML。每页的块从 0 编号。复用既有文字、栅格图片、简单 SVG 包装及表格解析。
- `BookPosition(block, offset, document)`：`document == null` 表示正文；非空时为 `supplementaryDocuments` 的键。`offset` 是该块规范化文字的 UTF-16 偏移，直接对应 Dart 字符串和 Flutter 文本位置。
- `BookContent.links` 收集正文和补充页的文字链接。`BookLink.document` 表示**来源**命名空间，`block` 及半开区间 `[start,end)` 在该命名空间内解释；`target.document` 表示**目标**命名空间。`href/kind/status/targetKey/target` 保留原含义。
- `BookContent.anchors` 的键仍是包内规范化路径和可选 `#解码ID`，值带目标命名空间。文档开头也有锚点；空文档和文末不可定位的空锚点移除，不错误落到下一页。同文档重复 ID 首个优先，不同文档的相同 ID 不冲突。

例如，正文中的引用链接可指向 `{document: "OPS/notes.xhtml", block: 0, offset: 0}`；该页的 backlink 可指回 `{block: 12, offset: 10}`。后者没有 `document`，仍表示正文第 12 块。不能把补充页的 `block: 0` 直接交给正文阅读位置。

## 兼容与持久化

- 补充内容、链接和锚点保存进既有 books JSON；图片仍存 `book_assets` BLOB，内容 JSON 格式不变。分页位置使用可空 `books.location`；历史迁移与当前schema以 `app/lib/db/database.dart` 为准，分页本身不重写正文JSON。
- JSON 缺少 `supplementaryDocuments` 时默认为空；位置和链接缺少 `document` 时默认为正文。序列化时省略空补充容器及空 `document`，旧正文位置的格式保持不变。
- 兼容没有 links/anchors 的旧 TXT/EPUB JSON，也兼容上一版仅有正文链接的 JSON。旧书不会自动重解析，已存正文块和阅读位置不被改写。
- 新书的补充页正文、简单表格、图片引用、链接范围和返回目标均可保存并重开；BLOB 随书籍沿用既有存取/删除路径。

## 书架作者与封面

- `BookContent.authors` 为可选作者列表，`cover` 为可选本地资源键；省略时分别为空列表/null，旧TXT/EPUB JSON不重写。沿用books.content JSON与book_assets BLOB，无数据库/schema迁移，不将图片字节写入JSON。手动书名仍由books.title拥有；作者/封面不改变正文、目录、锚点或阅读位置。
- 从OPF metadata的Dublin Core creator按文档顺序提取、折叠空白并去重；无角色的creator沿用，有明确角色时须包含aut才作为作者，只有译者/编辑角色不误标。兼容EPUB2的opf:role与EPUB3 refines角色，最多16名、每名最多256个UTF-16单元，过长名称忽略。依据见 [EPUB3 creator与角色](https://www.w3.org/TR/epub-33/#sec-opf-dccreator)。
- 封面依次尝试：manifest中第一个cover-image标记、metadata的meta name=cover所指manifest ID、guide中第一个type=cover引用。前两者须为本地PNG/JPEG/GIF/WebP；guide可直接指图片或manifest中本地HTML/XHTML，提取img或已支持的单张栅格SVG包装。不会猜测正文第一张图，不渲染通用SVG、不扫描其他页面、不遍历封面链接。标记依据见 [EPUB3 cover-image](https://www.w3.org/TR/epub-33/#sec-cover-image)，旧meta约定见 [IDPF样本](https://github.com/IDPF/epub3-samples/blob/main/30/page-blanche/EPUB/package.opf)。
- 仅封面新增资源最多5MiB，封面HTML最多1MiB；读取前检查声明大小，读取仍用原解压/实际大小/CRC检查，校验损坏继续拒绝整次导入。缺失、空资源、外链、查询参数、越界路径、超限、不支持格式忽略可选封面；坏图解码回退文字封面，不影响读正文。已有正文图片不重复存储，原整书与补充页限额不放宽。
- 书架沿用现有卡片和文字封面，作者以一行弱化文字显示，缺作者不造数据。图片按比例完整显示、限制解码至512×768范围且不放大源图；按可见卡片异步读取，不随书架全量读取BLOB；卡片销毁或换书时驱逐其缩略图缓存，避免小缩略图的MemoryImage键长期持有较大的原始字节。重新载入书架数据时同ID/路径也重新取图，覆盖备份替换场景。旧书没有原文件时不自动补作者/封面；重新导入才解析新元数据。
- 备份保存原始JSON与封面BLOB，预检检查cover对应资源存在；缺失时拒绝恢复，沿用现有事务替换和资源路径限制。自动回归入口：epub_metadata_test.dart、library_metadata_test.dart与backup_test.dart；原生视觉验收状态只见PLAN。

## 链接解析

- 提取普通文字中的 `<a href>`，识别 `epub:type=noteref/backlink` 和 `role=doc-noteref/doc-backlink`。没有语义标记的 EPUB 2 链接保留为普通链接，也能触发补充页加载，不靠文字猜测脚注。
- `_NormalizedText` 映射空白折叠前后的偏移；行内标签和表情不破坏链接范围。跨文本块链接拆为各块内有效范围，纯空白链接不生成范围。
- 先解析全部正文和原目录，再按链接顺序广度遍历补充页；最后统一解析链接目标，支持向前引用、返回正文及补充页之间的引用。缺 fragment 不回退章节首；目录旧有回退规则不变。

| status | 含义与阅读器行为 |
|---|---|
| resolved | 阅读器再次核对文档/块/偏移有效后，在独立阅读页定位目标 |
| missingTarget | 文件/锚点不存在，或已加载文档没有可定位内容；点击提示找不到内容 |
| unavailableDocument | 文件存在但未加载：不在 manifest、格式/固定版式不支持、超过加载或遍历限额等；点击提示尚未载入 |
| external | URI 有 scheme/authority，包括 javascript；点击提示书外链接，既不联网也不调用系统打开 |
| invalid | 错误转义、越界路径或暂不支持的查询参数；点击提示格式不受支持 |

## 加载边界

只按已提取的文字链接加载 manifest 中本地 `application/xhtml+xml` / `text/html` 文档，不扫描并载入全部独立页面。未引用页不加载；spine 中标为固定版式的非连续页保持 unavailable。规范化路径 visited 集合去重，正文不重复解析；自引用、别名和循环引用不会再次入队加载。

| 限额 | 实际实现 |
|---|---|
| 补充页数量 | 最多 64 页（包含已加载空页） |
| 单补充页解压大小 | 最多 1 MiB，解压前检查声明值 |
| 补充资源总量 | 最多 8 MiB，包含补充页和新加载图片；重复资源、已载入的正文图片不重复计费 |
| 引用遍历 | 最多检查前 4,096 个已提取链接，正文在前、补充页随后；重复/外链/无效链接也消耗检查次数 |
| 链深度 | 正文为 0，补充页最多第 8 层；按广度优先保留首次最短到达路径 |

超限页保持 unavailableDocument；图片若超出补充总限额则保存明确文字占位，仍可定位并保存所在页。预算拒绝不会为该图片扣减字节。超出遍历界限的链接如果目标已由其他路径加载，仍可正常解析到已有目标，但不会因此额外载入文档。

继续复用整书保护：原文件 50 MiB、单 ZIP 资源 20 MiB、声明总解压 150 MiB、ZIP 项 10,000；拒绝越界/重复路径、加密/DRM、异常解压大小和 CRC 不符。补充资源也经过实际输出大小与 CRC 校验，校验失败会拒绝整次导入。所有资源只从包内读取，不执行脚本、不下载外链。

## 阅读交互

- 文字链接加下划线；按实际文字选区命中，优先于单词查找。数字/标点及跨行链接可点击，段落空白不误判成最近的链接。普通文字点词、松手后长按复制句子沿用原手势。
- `ReaderPage._linked` 在独立路由中复用文字、图片、表格、点词与当前阅读样式；`linkTarget.document` 选择正文或补充容器，局部块索引只在对应容器内解释。链接文字也可指向正文中的脚注或跨章节引用。
- 初始定位到目标块；滚动模式按 UTF-16 偏移滚动，分页模式按同一源位置选页，使长段落内目标可见。文档末尾受滚动范围约束时不保证目标贴顶部；图片/表格目标定位到整个块。
- 原阅读路由保留，链接路由的滚动、分页进度控制、生命周期事件和返回都不写书籍进度。跳转后保留原有返回书架、目录、阅读设置、翻页与当前文档进度控制，另外提供返回上一处/原阅读处；不切换为精简专用面板。应用关闭重开恢复已存正文位置（滚动为块，分页为精确源锚点），临时链接浏览栈不持久化。
- 跳转页使用同一 ReaderSettings；设置值及单书/全局选择同步到父阅读页，由正文统一持久化，返回后仍然生效。主动选择目录项会结束临时链接浏览并定位正文章节，补充页不把其局部块号套进正文目录；返回书架也由正文保存队列统一退出。更改字体/阅读模式后的返回按源位置重新排版，不承诺旧像素坐标不变。
- 顶部“返回上一处”及系统返回逐层退出；“回到原阅读处”关闭全部链接页，保留原正文滚动位置与工具栏显隐状态。同一视口几何下按像素恢复；旋转或窗口尺寸变化后的排版另受 Flutter 布局影响。
- 如果目标的文档/块/偏移与某层来源位置完全匹配，直接退回该来源路由，支持未标记语义的 EPUB 2 backlink。未精确匹配的 backlink 仍按真实目标打开，可用顶部返回回到来处，不猜测返回位置。
- 防止快速重复点击创建多页，最多打开 16 层链接页；循环点击达到上限时提示先返回，不影响关闭功能。保持亮屏由原阅读页拥有，关闭脚注不会取消原正文的亮屏状态。
- 搜索结果复用此路由并独立高亮命中；结果列表保留在reading-search路由。全部返回/目录/退出会正确结束搜索与链接临时栈，真实backlink跳过中间搜索页；契约见 `search.md`。
- 书签复用同一临时链接路由并传完整PageAnchor；不将书签误判为EPUB返回链接。保留图注/表格行及补充文档命名空间，添加/删除和跳转契约见 `bookmarks.md`。
- 生词原句使用独立临时根阅读路由，可复用这些链接、设置和目录控件；其自身及嵌套页均不保存正文进度，返回生词本。图注与表格来源定位边界见 `vocabulary.md`。

## 分页与位置契约

### 文字分页基础与位置映射

`app/lib/reader/pagination.dart` 的 `TextPaginator.paginate` 复用 `BookPosition`；调用方指定正文或一个补充文档，独立得到 `TextPagination`。本层不写数据库，也不改变正文块、JSON 或脚注返回目标。

- 输入视口已由调用方扣除安全区及顶部/底部控件空间。分页器再扣除水平 `max(style.margin, (viewport.width - 680) / 2)`，得到 `contentSize`。文本样式、标题字号/字重、段落间距沿用滚动阅读器；平台字体、文字缩放、方向及 locale 必须与实际渲染一致。
- `pages` / `lines` 不可变。`TextPageLine` 保存原块半开区间 `[start.offset, endOffset)`、`start.document`、原段落的 `sourceTop/height` 和页内 `top/baseline`。通常对应一行；字体回退将一个字素排到多行或空行范围有歧义时，合并成不可跨页的带，保证 Unicode 字素完整、布局高度保留。
- 原始文字不 trim、不追加、不截断。相邻带的逻辑边界分配行尾空白及换行；空块保留一个空行高度、原文范围仍为 `[0,0)`。渲染接入时须按原段落同宽排版后裁剪，不能将每页子串重新排版，否则字形连接/两端对齐和定位可能变化。
- `pageForPosition` 按文档/块/UTF-16 偏移查页；页面起点由 `pages[index].start` 取得。页边界归后页，块末尾 caret 归该块末页；外部文档、未知块、负值或超长偏移返回 null。页码仅为当前布局结果，重排后用同一 `BookPosition` 再查页。
- `BookPosition(book.position)` 可将旧整数正文进度解释为原块开头；纯布局层不负责持久化；分页 UI 通过下述源位置契约保存段内位置，旧整数块号仍保留。
- 页首不保留段间/标题上方空隙，避免空白页；空文档返回空页列表。不可拆分带高于视口、或字形宽于可用宽度时仍输出并标记 `overflows`，UI 需处理该状态，不能静默裁掉文字。非法视口/样式、未知文档直接报参数错误；图片/表格显式抛 `UnsupportedError`，不静默遗漏。
- 长段（至少64物理行）的非空行通过 [Paragraph.getLineNumberAt](https://api.flutter.dev/flutter/dart-ui/Paragraph/getLineNumberAt.html) 在逻辑UTF-16位置上二分定位起点，再对齐字素簇；不依赖英语或视觉左右顺序。短段、空行及相邻行、引擎返回不明确位置时保留旧getPositionForOffset/getLineBoundary查询，保持控制字符/空行的原有合并语义。源段落和PageAnchor格式不变，不截断原文、不提高单段或缓存限额。回归对照见 `line_boundaries_test.dart`，基准命令见 [诊断说明](../app/benchmark/README.md)。
- 正文章节在下一物理页开始：`BookContent.chapterStarts` 从现有 `contents` 派生（显式目录含子级条目优先；无目录沿用 heading），过滤越界并按块去重。`TextPaginator` 与 `BookPaginator` 在章节块前结束非空页，首章/重复条目不产生额外空页，图片/表格起章同样生效。iPhone/iPad/Android 共用；双页可从左页或右页起章，不为对齐左页插空白。补充脚注不套正文边界；滚动模式不加整屏空白。无 JSON/schema 变化，已有书无需重导入，位置仍按源锚点保存；有目录时非目录小标题不强制换页，无目录旧 EPUB 的 heading 无法进一步区分标题级别，沿用其既有目录回退语义。
- 文字基础层同步测量，使用与TextPainter相同的ParagraphStyle/TextSpan生成原生Paragraph，逐段释放；不改变完整段落的排版或绘制。媒体与协作让出由下方组合分页器处理；会话缓存和性能验证边界见后文。

回归入口 `pagination_test.dart`：文字守恒、源位置、Unicode/空块、重排、章节边界与极小视口；实际字体布局/选区与绘制交叉检查。

### 图片与简单表格分页基础

`reader/book_pagination.dart` 的 `BookPaginator` 组合 `TextPaginator`，输入相同视口/样式/字体环境及目标文档，再传入 `imageSizes`；文字算法没有被替换。输出 `BookPagination.pages`、不可变 `BookPage.fragments`，包含 `PageTextFragment`、`PageImageFragment`、`PageTableRowFragment`。

- `loadPaginationImageSizes` 通过调用方提供的 `Future<Uint8List?> Function(String)` 读取目标文档引用的去重图片（既可用导入时 assets，也可用数据库 BLOB）。逐个读取编码描述信息取得像素尺寸，不实例化解码像素帧；描述对象和 buffer 在 finally 中释放。缺失、空、编码损坏、I/O 异常、超过 20 MiB 的单个编码资源不提供尺寸，分页时为明确的 unavailable 占位。函数不联网、不改内容或数据库。
- 调用方须先完成尺寸加载再分页。图片按比例缩小到可用页宽/页高，不放大；水平居中。缺失/非法尺寸使用全可用宽、`min(260, 页高)` 高的占位，不静默移除图片。图片不按剩余半页高度临时压缩，放不下则另起页。
- 非空且不是默认“图片”的替代文字作为图注，以 0.8 倍字号及原绝对字距布局，保留原块 UTF-16 偏移；图注前 8 间距，跨页时不保留页首间距。长图注可续页，图片与图注不保证强制同页；独立 figcaption 正文块仍按原顺序处理。
- 简单表格沿用每列 160、单元格每侧 10 的规则；按最长行补齐列，文本采用实际字体/缩放/方向/locale 测量，首行 `tableHeader` 加粗。整行高度为最高单元格文字高度加 20，不拆行、不重复表头；放不下的普通行到下一页，超高行整行保留并标记 `overflows`。宽表或单元格字形超宽同样标记溢出，UI 必须提供可达的内容展示，不能直接裁掉。空表保留一个 `emptyTable` 占位行，空单元格保留一行高度。
- `PageAnchor` 包含原 `BookPosition`、`PagePart`（text/image/caption/tableRow）及可选表格 `row`。UTF-16 偏移仍只用于原文字，不把表格行号伪装成文字偏移。`pages[index].start` 配合 `pageForAnchor` 可精确往返，包括图注续页和表格行续页；文字/图注的块内查找用二分定位。该源锚点通过下述版本化格式持久化，不能保存临时页码代替它。
- `pageForPosition` 保留旧链接语义：文字按原偏移查页，表格块 offset 0 到首行，图片 offset 0 到图片；图片非零原文偏移可查对应图注。没有图注的默认替代文字仍定位图片。表格非零 offset、错误文档/块/偏移或不匹配的精确锚点返回 null。正文与补充文档各自布局，补充行不会改变正文页数或进度。
- 宽表/超高行输出完整片段与溢出状态，由下述 UI 提供横向/纵向滚动及完整内容入口；原块顺序和内容 JSON 不变。

回归入口 `book_pagination_test.dart`：纯文字一致性、图注/表格守恒、媒体缺失与解码限额、布局尺寸及源锚点重排。

### 手机分页 UI 与精确位置保存

- 阅读设置提供“上下滚动 / 左右翻页”，新用户默认分页；旧 JSON 缺少 paged 或显式 false 保留旧滚动语义。landscapePaged 独立缺省 true，在宽横屏单独保存；模式沿用全局/单书样式，脚注沿用打开时的样式。单/双页的紧凑阅读区见下文。
- `PagedReader` 在会话缓存未命中时按下方入场调度契约加载图片尺寸，再调用可取消的 `paginateAsync`；显示加载提示，旧尺寸/样式结果通过 generation 丢弃。按块/表格行协作让出事件循环（累计约 8ms 后让出，不保证单次排版低于 8ms）。单段/图注或一行单元格总计超过 40,000 UTF-16 单元时提供“改用滚动阅读”。缓存未命中时仍须整份目标文档完成才展示页数；会话缓存已实现，见下文。尚无逐章首次展示或大书性能达标证明。
- 页面合并同段连续片段，以同宽、同字体环境排版**完整原段落**，按 sourceTop 裁剪平移；复用 `paragraph.dart` 的文字命中、点词和松手后长按复制。不能对子串重新排版。图注也可查词；图片从缓存的 BLOB 显示。宽表横向滚动，超高页纵向滚动；溢出页另有“展开本页内容”，以可选择文字查看完整段落/各单元格，避免极端字形被裁后无法读取。
- 左右滑动翻页，上一页/下一页及正文进度定位放在临时阅读操作面板；页底章节/页码仅显示信息，点击打开面板，不直接翻页。表格内部横向滚动不翻页，可用面板翻页离开。目录/脚注继续按原 BookPosition 定位。脚注路由各自分页、返回保留父路由精确锚点，任何补充页操作不写正文进度。
- schema 2 → 3 仅 `ALTER TABLE books ADD COLUMN location TEXT`；schema 1 同时补原有 assets 表。内容 JSON、资源、样式、旧整数 position 不作数据重写。`savePosition` 同次写入整数块号和可空 location；旧滚动写入清除过时 location。
- `PageAnchor.encode/decode` 格式为 `{version:1,position:{block,offset,document?},part,row?}`；行号只属于 tableRow，页码不入库。旧/缺失/格式错误或未知版本退回原整数块起点，恢复时按现有块和长度限定范围。正文不接受补充文档 location。
- 翻页更新页起点源锚点；目录/脚注精确跳转保留传入偏移。字号、边距、文字缩放、视口变化重排时保留同一源锚点，重新查页；页首可能变化，目标原文仍在该页。重开恢复段内/图注偏移或表格行。超高页的内部滚动像素不持久化，恢复到该行/带开头。由分页切到滚动后仍沿用旧块级定位。
- 回归入口 `paged_reader_test.dart`：旧库迁移、位置/设置兼容、取消/限额、分页/查词/复制/重排/重开、脚注隔离、媒体及超长内容回退。

### 单/双页与紧凑阅读区

- `ReaderStyle.isWideLandscape` 以应用窗口宽 ≥900、短边 ≥600、宽大于高判断双页；不把横屏手机误判平板，竖屏/窄分屏为单页。中缝 44，每栏按自身宽度分页，左右连续放置；PageView 的一个 item 是一个单/双页组合。按当前源锚点定位页再取组合，不以组合左页覆盖右页目标；点击右页更新焦点源位置，旋转、重开、脚注返回保留该位置。
- 一次滑动前进/后退一个组合；目录/进度仍接受真实页索引。奇数尾页右边为空，不复制正文、不制造可跳转空页。展开溢出内容覆盖当前组合的两页，宽表内部横向滚动保持原行为。
- 手机与平板分页均采用紧凑阅读区：安全区内手机正文上边距20，窗口短边 ≥600 时为32，底部自然边距40，页码位于其中。分页器按实际正文视口测量；尺寸改变后保留源锚点，临时页码可变化。手机滚动模式不套用分页边距。
- 无常驻顶部书名/信息栏；正文自身的章节标题不删除。底部居中 11 号、现有 ink 45% 透明度，以主题辅助字体显示 `章节 — 1–2 / 总页数`。章节来自当前源锚点对应的 EPUB 目录，或 TXT 已识别标题（BookContent.contents）；没有可靠标题只显示页码，补充页不冒用正文章名。长章名省略，页码完整保留；不显示百分比、电量或仿制 Home Indicator。
- 没有常驻底部箭头/滑条。点击正文空白或底部信息打开临时操作面板，包含返回书架/上一处、目录、设置、翻页及正文进度定位；需要时可展开完整溢出内容。查词气泡存在时先关闭气泡，再点击可开面板。加载/错误状态仍可点空白打开返回入口。这些浮层不改变正文视口、不触发额外重分页。手机与平板分页共用此行为。
- 横竖方向模式不同导致分页/滚动切换时，保留当前内存源锚点直至用户在滚动模式实际移动；显式滚动保存仍按既有块级契约。没有新增数据库或位置格式。
- 双页回归复用 `paged_reader_test.dart`：左右页组合、右页目标、旋转/分屏、奇数尾页、宽表展开与实际视口分配。

### 链接与补充页回归入口

- `epub_links_test.dart`、`footnote_fixture_test.dart`：EPUB2/3、来源/目标命名空间、UTF-16、旧JSON、正文不变、资源预算、循环/别名、路径与CRC拒绝。
- `reader_links_test.dart`：点击/查词/backlink、非零正文位置、重开与临时导航隔离、长段落/媒体/表格目标、逐层返回、多层及快速重复点击、跨行/空白手势。
- 真实小说的历史指纹/资源对照见 `real-epub-compatibility.md`；当前验收范围只见PLAN。

## 不支持的内容范围

- 脚注使用独立阅读页，不提供另一套脚注弹层；设备验收状态见PLAN，不在此重复维护。
- 表格单元格内的链接、图片链接、旧式 `<a name>` 锚点；其文字提取沿用原逻辑。
- 通用 SVG、CSS 精确排版、隐藏样式语义、固定版式或复杂公式。真实教材与大书的验证缺口见PLAN。

## 普通正文目录返回

- 正文目录选择仍是正常阅读跳转：目标和后续翻页按既有规则保存进度。首次跳转前记录一个内存返回点，连续选择目录保留最初来处；“返回目录跳转前”恢复该位置并清除入口，再次目录跳转建立新的返回点。离开书籍或关闭应用不保存这个返回点，重开沿当前已保存进度。
- 入口追加在原阅读操作面板及手机滚动模式工具栏，保留设置、目录、搜索、书签、返回书架和进度控制；紧凑正文与薄底部信息分配不变。系统返回仍按原行为退出/逐层返回，不隐式触发目录回退。
- 分页保留完整PageAnchor，包含UTF-16文字偏移、图注或表格行；`PagedReader.jumpAnchor`与普通jump共用归一化/选页/发布逻辑。返回后按当前字号与方向重新排版，保持源锚点而非旧页码。
- 滚动记录首次可见块和相对视口位置；窗口及样式未变时恢复其屏幕位置（包含部分滚出顶部的段落）。改变字号、方向或阅读模式后按原块/分页源锚点回到相应内容，不承诺旧像素位置；滚动自身的持久化仍是原块级语义。
- 从脚注、书签或搜索临时页选目录，仍结束临时浏览并转交正文，返回点取保留的正文位置，不误用补充文档块号。生词原句临时根保持原有临时目录浏览/返回、不写正文进度，也不创建普通正文目录返回点。
- 快速重复点击同一个目录弹窗只处理一次，延迟跳转使用代次防过时请求。无需schema、内容JSON或ReaderStyle格式变更。

## 阅读页入场与分页调度

- 分页模式进入阅读路由时，等待路由的正向入场动画完成后再读取分页图片尺寸并计算布局，避免整书文字测量与滑入动画同时占用UI线程。不改变入场动画本身或阅读区分配。
- 等待期间配置改变沿用generation取消旧任务；返回/销毁释放动画监听与等待，不启动已退出页面的分页。无入场动画时按原流程直接计算。
- 此调度本身不使分页后台化。缓存未命中时仍须完成目标文档分页后显示正文；同会话重开若命中下述缓存则直接复用，App重启后重新计算。真实帧耗时须用真机Profile测量，Debug体验不代表Release性能。

## 会话内分页缓存

- 数据库读取Book时附带原content JSON快照（非新字段、不再次编码）；共享PaginationCache按书籍ID、精确源JSON、正文/补充文档、视口与列数、字体排版参数、文字缩放、平台、方向和locale复用已完成布局。BookContent在读取后按不可变数据使用，未提供持久化快照的临时Book沿原计算流程。
- 缓存命中立即建立当前阅读位置对应的PageController，不复用旧页码/旧阅读位置；仍通过完整PageAnchor定位文字、图注及表格行。主题、释义语言/档位等不改变测量尺寸的设置不触发重排。
- 最多3份LRU布局，16MiB估算留存预算（源JSON字符、页/片段/单元格的保守计数，不是精确VM堆内存上限）；超限布局仍可正常阅读，只不缓存。缓存不包含图片像素；有图片尺寸缺失的布局不缓存，允许重开重试。
- 删除书籍清除该书布局；整库恢复成功清空缓存；数据库provider替换/释放及系统内存压力清理缓存。缓存清理代次阻止旧在途计算重新填入。当前正在阅读的布局不因清理缓存而消失。
- 只在同一次App运行期间复用，重启仍首次分页；未实现磁盘分页索引或按需渐进分页。书架原有全量解码仍保留，Book源快照增加的活跃书籍字符串内存不属于缓存预算，超大书库的总体内存仍需Profile验证。

## 图片查看器

- 正文分页/双页、滚动及补充文档图片点击后进入共用临时图片查看页，复用现有本地资源字节，不打开外部链接。图注仍是原点词区域；已有释义时第一次点击图片仅关闭释义，第二次才放大。
- 双指缩放1–5倍、放大后拖动、双击2.5倍/还原；另有放大/缩小/还原按钮及关闭入口。系统返回只关闭查看器；快速重复点击不叠加路由。旋转后还原图片变换，原阅读页继续按既有源锚点重排。
- 查看器沿阅读主题，不修改书内图片尺寸、分页结果、目录/脚注返回栈或正文位置。关闭后仍是原ReaderPage；生词原句/补充文档不会因查看图片改写正文进度。
- 查看器输入不超过20MiB；读取元信息后将解码目标限制为最长边4096、最多8Mi像素，不主动放大小图。大图可降采样，因此放大不保证显示原图全部细节；不引入远程请求、原图导出或图片编辑功能。坏图有可关闭错误状态，描述器/字节buffer及时释放。

## 阅读器职责地图与修改边界

此表描述现有结构，不表示已经拆分了阅读协调器。

阅读方向的偏好、会话与平台限制由独立`app/lib/orientation/`维护，ReaderPage只装配；见 [阅读方向契约](orientation.md)。

| 路径（app/lib/reader/） | 当前职责 |
|---|---|
| reader.dart | 路由/临时返回、样式/位置保存协调、查词与功能入口、滚动正文及操作面板；不应继续承载新模块的独立UI或算法 |
| paged_reader.dart | 分页生命周期、几何与缓存接入、PageView呈现和手势回调 |
| pagination.dart / book_pagination.dart | 文字/媒体/表格布局和稳定源位置映射；不引入业务数据库或临时导航 |
| pagination_cache.dart | 有界会话留存与清理，不保存阅读进度或图片像素 |
| paragraph.dart / bubble.dart / image_viewer.dart | 文字命中/选区、点词释义、图片查看各自的呈现与交互 |
| selection.dart | 同一文档当前屏幕跨段/双页选区，源片段覆盖与临时范围清理；不保存位置，不自动翻页；[选区契约](translation.md#拖动选区与短语) |

当相关修改出现重复状态或需要多处同步修改同一职责时，优先评估抽离一块，例如操作面板UI；先固定输入/回调与临时跳转不写正文位置等不变量，再做专项回归。源文件行数不是独立重构理由；尚未提取的职责不标记为完成，首次分页性能定位不自动扩成全面重构。
