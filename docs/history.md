# 查词历史契约

进度、验证与下一步只维护在 `../PLAN.md`。

- 书架 → 更多 → 查词历史。保留最近200个查过的原词；这是自动查询记录，与主动收藏的生词快照分开。列表本身不打开词典，不请求翻译。
- 阅读器词典查询完成且当前气泡仍有效时记录，包括确认未收录；词典加载/查询失败、完成前已关闭/换词不记录。用于退出释义的点击、展开、切换释义语言、长按句子/短语翻译不新增历史。机器翻译失败不撤销已完成的查词事实。
- schema7仅新增 `lookup_history(lang,word,looked_up_at)`，主键为语言和精确原词；`May`与`may`分别保留，不把原词替换成词典原形。不保存正文、释义、书籍引用或虚构来源，不自动写生词本。
- 查询按调用顺序串行入库，重复原词置顶；按rowid保留最近200条，不依赖系统时钟单调递增。looked_up_at用于显示本地查询日期。单词非空、无首尾空白/ASCII控制字符、最多256个UTF-16单元；语言代码非空、最多32。超限不影响查词，只不记历史。数据层保留语言字段，V1仅开放英语查询，不提供学习语言切换。
- `LookupHistory`写队列与代次使清空/恢复先失效较早查询，再等待已开始写入；旧查询即使晚到也不能复活清空的历史。失败不会污染后续队列。自动记录失败不妨碍显示释义；本会话历史列表提示可能有未保存记录，成功清空/恢复后重置提示。
- 按最近查询排序，字面子串搜索（忽略大小写，百分号/下划线不作通配符）。点击记录重新查询当前词典，使用全局主释义语言与现有完整WordBubble；重新查询成功置顶，失败可重试。真正未收录使用已有机器翻译兜底，标注及下载规则沿用dictionaries.md。没有来源原句，因此不提供收藏或回到原句；不写正文进度。关闭后保留搜索条件，刷新排序。
- 清空必须确认，取消不写数据；只清历史，不清词典、书库、生词或译文缓存。空列表、无匹配、读取失败重试、清空失败均有反馈。列表最多200条并按需构建；窄屏/长词/大字号可滚动。
- 备份v1容器继续使用，新导出payload为schema7并包含七张表；schema6旧备份预检时补空历史。整库恢复会替换历史，包括使用旧备份时清空现有历史；预览列出数量和替换提示。顺序按rowid导出/恢复，保留历史次序。历史非法字段、重复键、超200条及schema7缺表均拒绝整次恢复，失败事务整体回滚。详见backup.md。
- 无云同步、背词复习、学习统计、历史导出或任意语言查询；不将历史列表当作生词收藏或学习进度。
