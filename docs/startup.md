# 启动续读契约

## 用户行为

书架“更多 → 启动设置”提供“启动时继续阅读”开关。默认关闭；关闭时沿用原有书架首页和引导入口。该开关是应用设置，独立于阅读排版和每书样式，不改变现有阅读设置面板。

开启后，仅在应用根页面首次创建时尝试一次，打开书架中最近读过且仍存在的书。选择沿用数据库书架排序 `last_read_at DESC, created_at DESC`，要求 `last_read_at > 0`；新导入但未读的书不会成为候选。没有候选就显示书架；删除最近已读书后，可继续下一本仍存在的已读书。返回书架、应用回到前台、切换主题、重建列表、修改开关或恢复备份均不会立即重新自动进入阅读；开关作用于下一次启动。

启动协调层复用书架已经加载的书对象，不再为续读查询/解码第二份大书。进入现有ReaderPage，保留Book.position/Book.location和每书样式，使用现有全局样式作为缺省值；单/双页和滚动、分页入场时机、正文源锚点规则沿用 [阅读契约](epub-links.md)。协调层不改写位置，阅读器仍按原有策略保存当前正文位置及最近阅读时间。

自动打开前必须满足：根页面仍存在、仍是当前页面、用户尚未开始操作、没有待处理外部文件，且最新收件快照可确认。用户触摸书架或进入其他页面会取消本次自动打开，避免慢启动打断已开始的操作。读取设置/书架/样式失败时回退书架或其已有错误重试界面，不阻塞手动打开书。

## 外部文件优先

订阅当前收件箱；有文件接收中、可导入文件或错误提示都取消自动续读。导航前再刷新原生收件快照，平台暂时无法确认时也留在书架。文件到达自动打开之后则沿用现有“当前阅读不被打断、返回书架再导入”的行为；不能据此承诺来源App任意延迟投递都发生在进入阅读之前。完整文件入口和限制见 [导入契约](import.md)。

`ImportInbox.refresh()` 返回本次最新快照是否可确认；乱序/销毁/平台错误返回false，保留已有收件状态。无手机插件的宿主按没有原生收件入口处理。未增加原生方法或平台权限。

## 设置与备份

设置键 `resumeReadingOnLaunchV1`，值 `'1'` 开启、`'0'` 关闭；缺失或其他值按关闭处理。使用现有settings表，无数据库迁移、额外书籍ID或重复进度。AsyncNotifier在应用作用域更新成功写入的值；写入失败保留原值并允许重试。保存期间关闭面板不丢失已成功保存的状态。

普通settings记录随整库备份恢复；旧备份缺项则默认关闭，未知字符串不会误开启。恢复成功刷新开关provider，但不重新运行启动导航。旧版本忽略该设置即可保持自身启动方式；备份封装/schema及事务规则保持，见 [备份契约](backup.md)。

## 结构与验证

- `app/lib/startup/startup.dart`：启动时机、取消与导航；首页仍保留LibraryPage作为返回目标。
- `app/lib/startup/preferences.dart`：全局开关读取、写入和设置面板。
- `main.dart`挂载启动组件；library更多菜单增加入口；backup恢复后刷新开关；不向reader.dart增加启动逻辑。

`app/test/startup_test.dart`覆盖默认/异常设置、最近已读书与精确锚点/每书样式、返回/前台重建不重开、空书架/未读/删除、收件优先、未知收件状态、慢启动用户操作/销毁、保存失败/关闭面板和旧备份。`backup_test.dart`补验真实恢复流程刷新开关且不自动导航；原外部导入回归保持。

宿主导航测试和构建不替代手机进程生命周期体验。真机启动/系统杀进程重开及两端外部文件投递统一见 [PLAN](../PLAN.md) 待验清单；不以应用切回前台模拟一次全新启动。
