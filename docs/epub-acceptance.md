# EPUB 基础版本验收

范围：可重排 EPUB 2/3，滚动阅读，文字、包内 PNG/JPEG/GIF/WebP、简单表格。遵循 [W3C EPUB 3.3](https://www.w3.org/TR/epub-33/) 的容器、清单、spine 和目录结构。

## 实现

- 原目录（EPUB 3 nav / EPUB 2 NCX）及嵌套层级、章节内 ID 跳转；缺目录时使用正文标题。
- 书籍元数据标题、按 spine 顺序阅读；正文和表格单词沿用离线 ECDICT 气泡，长按复制仍可用。
- 本地图片独立存为 SQLite BLOB；正文 JSON 不嵌入图片，旧 TXT/设置/阅读位置可迁移。
- 位置保存精确到内容块；图片使用稳定高度避免异步加载时正文跳动。表格可横向滚动。
- 输入上限 50 MB、单资源解压上限 20 MB、总声明解压上限 150 MB、文件数上限 10,000；流式解压检查实际输出大小、CRC，拒绝越界路径、ZIP 加密、DRM 和固定版式。外部资源不联网获取，脚本不执行。

## 自动验证

`app/test/epub_test.dart`：EPUB 2/3、spine 与 manifest 顺序不同、嵌套目录与片段定位、图片带空格路径、表格、旧 JSON、旧库升级及关闭重开、图片删除清理、损坏/越界/伪造解压大小/DRM/固定版式、缺图占位、合并单元格明确降级。

`app/test/file_import_test.dart`：替代系统选择对话框，实际读取 EPUB → 后台解析 → SQLite → 阅读页 → 图片 → 表格离线查词保持 → 目录跳转 → 返回书架 → 重开恢复；EPUB 2 使用手机尺寸 430×1000，EPUB 3 使用平板横屏尺寸 1180×820。这是组件测试，不等同于 iPad 设备验收或原生文件选择验收。

样本由 `scripts/make_epub_fixture.py` 确定性生成，原创正文和图片，在 `app/test/fixtures/epub/`；不包含外部版权书籍。

## 尚未验收/实现

- 原生文件选择器真实选取 EPUB、用户真实书籍和大书表现尚需实测。
- iPad 模拟器/真机、双页、左右翻页未完成。当前只确认通用工程和横屏布局组件。
- 本轮不支持 DRM/固定版式、公式、SVG、原书 CSS/内嵌字体精确排版、脚注链接跳转、图片放大。合并单元格/嵌套表格按行降级并注明，不能视作复杂表格完整支持。
- 章节内容按 UTF-8 解码；其他 EPUB 文本编码兼容性待后续验证。
- 翻译、生词本、书签/搜索、备份仍按阶段 3 后续推进。
