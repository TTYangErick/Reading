# 书内搜索契约

状态与下一步仅维护在 `../PLAN.md`。

- 阅读操作面板/滚动顶部增加“书内搜索”，进入独立搜索页。输入关键词或短语，默认忽略大小写，可选择区分大小写；输入后300ms搜索，提交立即搜索。V1仅支持英语学习，本模块不添加学习语言或词典切换。
- 字面子串匹配（非正则、非整词、无词干/模糊搜索）。按Unicode scalar作Dart简单小写转换，连续空白合并为一空格，查询首尾空白忽略；不做重音去除、Unicode规范等价转换或语言专用大小写折叠。显示换行不影响匹配，原文显式空白也可匹配单空格短语；不跨源块或表格单元格拼接。
- 范围为整本已解析内容：正文文字、图片图注、表格各单元格、已载入补充文档。没有OCR，不搜索未载入脚注、图片像素、文件名或未保存的EPUB结构。顺序为正文源块顺序、单元格行列顺序，再补充文档存储顺序；结果显示段落/媒体/补充文档位置及匹配上下文。
- `BookSearch`流式KMP匹配，保留归一化单位至原始UTF-16偏移映射，Unicode代理对不被截断；结果的BookPosition包含真实匹配偏移/补充document，表格另带cell行列，PageAnchor使用tableRow/行号与偏移0，图注使用caption。读取不可变BookContent，不改原文、位置或数据库，不创建全文索引。
- 默认最多返回500条，发现第501条后标明仅显示前500条；扫描预算2000万UTF-16单位或10万源片段，达到预算明确提示搜索未覆盖全部内容，不将部分结果冒充完整结果或证明没有匹配。查询最长200 UTF-16单位，过长提示缩短。每约8192单位让出事件循环，新输入/清空/离页取消旧扫描并拒绝旧结果或错误覆盖新状态。结果前后上下文与匹配预览分别有长度限制，不为巨大空白匹配构造巨大显示字符串。
- 结果页有加载、空查询、无匹配、限制说明、失败重试状态；长列表按需构建，输入键盘使用Scaffold正常避让。连续点击只打开一个目标。搜索页留在导航栈，返回结果列表保留查询、大小写选项及列表位置。
- 目标复用reading-link完整阅读页，高亮命中并显露原文，保留设置、目录、书签、查词/翻译。表格按真实行列及单元格偏移定位，不把字符偏移当行号；高亮状态独立于点词气泡，不自动查询词典。
- 返回上一处/系统返回从目标回搜索结果；“回到原阅读处”结束临时搜索/链接栈，来自生词原句则沿现有“回到原句”；返回书架和主动选择目录仍沿原根阅读页行为。真实EPUB backlink匹配按阅读链接层级返回，同时跳过中间搜索路由。连续链接仍受16层限制，搜索结果本身不当作backlink。
- 搜索和临时结果浏览不保存正文进度；主动修改设置、主动从目录定位正文仍按原规则持久化。schema6、PageAnchor v1、ReaderStyle v1、既有生词/书签/缓存格式不变，无新依赖或权限。大量真实教材和低内存设备的搜索性能仍需专项体验，不由宿主测试推断。
